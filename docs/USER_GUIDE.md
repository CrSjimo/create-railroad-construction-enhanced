# 机械动力铁路施工增强 使用手册

本手册介绍机械动力铁路施工增强（RRCE）在游戏中的使用方式。RRCE 让你先以「控制点」勘测线路，再由「铁路施工图」按其上的设置，一次性修建直线、弯道、坡道、平行复线、路堑与隧道。所有施工都在服务端执行，多人游戏中服务端与客户端都需要安装本模组。

## 一、准备

- **游戏环境**：Minecraft 1.20.1 使用 Fabric Loader 0.19.5（另需 Fabric API）或 Forge 47.4.0，分别提供 Create 0.5.1-j / 0.5.1.j 与 Create 6.0 的独立产物；Minecraft 1.21.1 使用 NeoForge 21.1.219 与 Create 6.0.10。1.20.1 使用 Java 17，1.21.1 使用 Java 21。安装时必须匹配加载器、游戏版本和 Create 代际；不支持 Fabric 1.21.1 或 1.21.1 / Create 0.5。
- **可选模组**：安装 Create: Steam ’n’ Rails（气鸣铁道）可获得更多轨道材质；安装 Create Unlimited 后，在关闭放置检查时可同步放宽坡道与弯道限制。二者都不是必需依赖。
- **获取物品**：在创造模式物品栏的独立分组「铁路施工」中取出铁路施工图、五件控制点工具与四件快速规划工具。它们没有合成配方，取得后可在生存与冒险模式使用。
- **使用权限**：服务端只允许手持施工物品或拥有 OP 2 权限的玩家执行施工、命令与界面操作；旁观模式无法使用。

### 物品一览

| 物品 | 用途 |
|---|---|
| 铁路施工图 | 打开施工界面、设置线路参数并执行施工 |
| 添加控制点工具 | 插入新的轨道端点 |
| 选择控制点工具 | 选中已有的轨道端点 |
| 移动控制点工具 | 移动当前选中的轨道端点 |
| 调整控制点方向工具 | 旋转当前选中端点的轨道方向 |
| 删除控制点工具 | 删除当前选中的轨道端点 |
| 快速规划弯道工具 | 从选中端点向左或向右偏移线路 |
| 快速规划坡道工具 | 从选中端点向上或向下延伸线路 |
| 快速规划 45° 转弯工具 | 从选中端点向左或向右转 45° |
| 快速规划 90° 转弯工具 | 从选中端点向左或向右转 90° |

## 二、核心概念

- **轨道端点（控制点）**：由一个方块位置和一个水平方向组成。方向取八个水平朝向之一（东、东南、南、西南、西、西北、北、东北），并始终指向端点编号增大的那一侧——也就是说，列车沿箭头方向从编号小的一端驶向编号大的一端。
- **线路**：相邻两个端点之间的一段轨道。多个端点依次相接，构成整条线路的走向。
- **复线**：同一条线路可以横向复制成多条平行轨道，数量为 1–16 条。
- **施工图**：打开线路配置、预览与施工界面的物品。

## 三、勘测轨道端点

### 添加控制点工具

- 右击方块，在当前选中的端点之后插入一个新端点；若尚未选中任何端点，则追加到末尾。
- 端点的初始方向由你的视线决定；如果点击的是 Create 轨道，则方向会沿该轨道选取与视线最接近的一侧。
- 端点的落点：点击普通方块时取所点击面的相邻格；点击 Create 轨道且只设置两条线路时，会寻找相邻的平行轨道，把端点放在两条轨道的中心，便于接着已有的复线继续勘测。
- 约束：相邻端点不能重合，水平距离至少 2 格，整条线路最多 64 个端点；端点所在区块必须已加载，且位于世界高度范围内。

### 选择控制点工具

- 右击端点所在的方块，或直接瞄准悬空的端点标记后右键，即可选中该端点。
- 同一格存在多个端点时，重复右击会依次循环切换。

### 移动控制点工具

- 右击目标位置，把当前选中的端点移到该处，落点规则与添加工具相同。

### 调整控制点方向工具

- 右键使选中端点的方向顺时针旋转 45°，潜行右键则逆时针旋转 45°。旋转会立即反映在方向箭头与预览上。

### 删除控制点工具

- 右键任意位置即可删除当前选中的端点，与所点的方块无关。

### 快速规划工具

先选中一处端点，再手持对应工具右键。工具会沿选中端点的轨道方向，计算下一处端点并插入在其后；新端点随即成为选中端点。可以连续使用，也可以继续用普通控制点工具微调。潜行右键打开该工具的设置界面，设置保存在当前物品上。所点方块的位置不会改变快速规划的起点。

| 工具 | 可调设置 | 线路效果 |
|---|---|---|
| 快速规划弯道 | 前进距离默认 20 格；侧偏比例默认 0.05 | 前进时逐渐横向偏移。正值向右，负值向左；偏移距离约为前进距离乘以侧偏比例。 |
| 快速规划坡道 | 前进距离默认 20 格；坡度默认 0.05 | 正值上坡，负值下坡；高差约为前进距离乘以坡度。 |
| 快速规划 45° 转弯 | 转弯半径默认 20 格；直道延长默认 0 | 正半径右转，负半径左转，末端轨道方向转过 45°。 |
| 快速规划 90° 转弯 | 转弯半径默认 20 格；直道延长默认 0 | 正半径右转，负半径左转，末端轨道方向转过 90°。 |

转弯工具的直道延长为正时，直道位于转弯之前；为负时，直道位于转弯之后。端点必须落在方块格点上，因此工具会将计算结果取到最近一格。若新的线路不满足轨道转弯、坡度或复线间距要求，工具会拒绝这次添加，原有端点保持不变。

### 端点页

在施工图的「端点」页也可以编辑端点：上一点 / 下一点切换选中，删除选中点，按东、西、上、下、南、北逐格移动，顺转 / 逆转 45°，或清空全部端点。页面顶部显示当前选中端点的坐标与朝向。

## 四、线路如何连接

两个相邻端点确定一段线路，连接方式由两端的方向与相对位置自动决定：

- **直轨**：两端方向相同且处在同一直线上。
- **S 弯**：两端方向相同，但横向错开。
- **转弯**：两端方向相差 45° 或 90°。弯道遵循 Create「以最大半径转弯」的规则，不需要另外设置半径；当两端到切线交点的距离不等时，只沿较长的一侧补一段直轨，使弯道尽量大。
- 相邻两端的方向差不能超过 90°，否则施工会被拒绝。
- **坡道**：两端存在高差时按 Create 的坡度要求检查。直线坡道按高差限制最小水平距离；爬坡弯道按转弯半径与高差检查。S 弯不能同时带高差，需要留出水平的过渡段。
- **已有轨道**：若规划位置已有同材质、同方向的 Create 轨道，会直接复用；若已有不兼容的轨道、弯道或交叉，则拒绝本次施工。
- 预览会实时显示连接能否成立；无法施工时，护目镜或预览中会给出具体原因。

## 五、复线规划

- **并行线路数**：1–16 条。
- **线路间空格**：相邻轨道之间留出的完整方块数（默认 3），因此轨道中心距至少为「空格数 + 1」。
- **外侧路基宽度**：最外侧轨道到路基边缘的距离（默认 2）。
- 直道上的复线保持整数格点偏移；斜向轨道按最小可用的格点步长取整。
- 弯道处若复线间距不足，会自动微调接弯位置以尽量保持设定间距；若无论如何都无法保持间距，则拒绝施工并给出提示。
- **弯道主端**：每条线可分别指定弯道以起点端还是终点端为主端（对应 Create 弯道的主端）。默认两条线路分别取起点与终点，可在「材料」页逐线切换。
- 从已有的双线轨道继续勘测时，新施工段会在接缝处与原有双线对齐。

## 六、施工图界面

右击铁路施工图打开界面。界面分为五页，各页字段可直接输入数值，输入超出范围时会给出提示；底部是「保存、施工、撤销、重做、关闭」五个按钮。

### 线路页

- 并行线路数、线路间空格、外侧路基宽度。
- **预览**：开关持续预览。
- **显示模式**：在「线路轮廓」与「施工全貌」之间切换。

### 开山页

- 隧道障碍高度：超过此高度建隧道，否则开路堑。
- 开山坡角（度）：路堑两侧的放坡角度。
- 开山与隧道：关闭后只铺路基与轨道，不改动地形。
- 替换路基：开启时用规划的路基替换原有方块。
- 所有方块视为地形：开启后，所有非空气方块都计入障碍高度，开挖时也忽略受保护名单；该开关仅对当前施工图有效。

### 隧道页

- 隧道净高、隧道侧距、墙壁厚度、顶板厚度。

### 材料页

- 逐线选择轨道材质，可用上下箭头在已注册材质间循环；把材质栏清空表示该线只修路基、不铺轨道。
- 路基方块、隧道墙壁方块，输入栏左侧实时预览对应方块。输入栏留空时显示「不铺设路基」或「不修建隧道墙壁」；留空或使用空气时，预览框保持空白。
- 本线路的弯道主端（起点 / 终点）。

### 端点页

编辑轨道端点，详见第三章。

### 底部按钮

「保存」把当前设置发送到服务端并写入手持的施工物品；「施工」会先保存再执行；「撤销」与「重做」用于回退或恢复已完成的施工；「关闭」退出界面。

## 七、路基与轨道

- **路基方块**：可使用任意能承重的方块。若选择半砖，会按 Create 的铺路高度处理：平地使用整格厚的双层半砖，坡道按高度交替使用上半砖与下半砖，避免半砖顶面压进轨道。
- **未设置与空气**：清空路基或隧道墙壁字段，表示完全跳过该部分的材质施工，不铺设也不按材质清除原有方块；隧道墙壁留空时也不修建顶棚。填入 `minecraft:air` 则表示在该部分的规划位置写入空气，用于清除方块，路基仍遵循「替换路基」开关。两种设置都不会关闭原有的路堑与隧道内部开挖，开挖仍由「开山与隧道」开关控制。
- **轨道材质**：逐线设置，材质列表来自 Create 及已安装的兼容模组。留空表示该条线路只铺路基，但它仍参与线路走向与间距校验，可用于只修路基、日后再铺轨。
- **替换路基**：开启时按规划写入路基并替换原有方块；关闭时尽量保留已有的、能够承重的方块（不等于高出目标路基表面），无法保留时会提示开启替换。
- **开山与隧道**：关闭后只铺路基与轨道。此时轨道只能放在可替换的位置或已有轨道上。

## 八、开山与隧道

施工会从路基表面向上查找计入「地形」的方块，得到每格的障碍高度。相邻的路基格连成一片：整片障碍的最高高度超过「隧道障碍高度」时修建隧道，否则开路堑。

- **路堑（开山）**：按设定的坡角向线路两侧放坡并挖除，只在横向扩展，不会越过线路首末端点纵向扩挖。
- **隧道**：
  - 净高：隧道内部的高度（默认 6）。
  - 侧距：隧道两侧的额外净空（默认 0，侧墙紧贴路基）。
  - 墙壁厚度、顶板厚度：隧道墙与顶板的厚度。
  - 隧道端面保持敞开；当隧道正好触及线路的起点或终点时不会生成封口墙，端点以外的原有山体保持原样。
- **受保护方块**：默认规则下无法被施工挖除，会让施工失败。开启「所有方块视为地形」后，所有非空气方块都计入障碍高度，开挖时也忽略受保护名单，但轨道连接与位置冲突仍按原规则检查。默认会保护所有 Create 及兼容模组注册的轨道。
- 树木、冰、建筑等默认不计入隧道阈值判断，但只要落在开挖范围内仍会被清理。

## 九、服务端地形规则

服务器首次启动时会生成配置文件 `config/rrce-terrain.json`，用于决定哪些方块算作地形、哪些受到保护。

- `terrainBlocks` / `terrainTags`：计入障碍高度的方块或标签。
- `nonTerrainBlocks` / `nonTerrainTags`：从中排除的方块或标签。
- `protectedBlocks` / `protectedTags`：开挖时拒绝修改的方块或标签。
- `protectTrackBlocks`：默认保护所有 Create 轨道及兼容模组注册的轨道。

列表中使用完整的方块或标签 ID，例如 `minecraft:gravel`、`minecraft:base_stone_overworld`；标签 ID 不带 `#`。排除名单与受保护名单的优先级高于地形名单。修改文件后，可用 OP 2 命令 `/rrce terrain reload` 重载，或重启服务器。未知的方块 ID 或缺失的列表会使重载失败，并保留上一次成功加载的规则。

## 十、预览与工程师护目镜

- 预览默认开启，可在界面或通过 `/rrce preview` 切换。
- **线路轮廓**：绘制待施工方块的真实轮廓、弯道中心线与端点方向箭头。
- **施工全貌**：绘制玩家附近（最多 1600 个）半透明方块模型与 Create 弯道模型；与规划重叠的现有方块以及待挖除的方块会暂时从画面中隐藏，关闭预览后恢复显示，世界方块不受影响。
- **颜色约定**：青色为轨道，绿色曲线为弯道，金色为路基，灰色为隧道墙，红色为挖除范围；黄色框表示轨道端点，绿色框表示当前选中的端点。
- **工程师护目镜**：佩戴 Create 工程师护目镜并手持任一施工物品时，右上角会显示线路数、直线路基宽度、端点数 / 弯道数，以及预计施工范围或无法施工的原因。

## 十一、施工、撤销与重做

- 点击「施工」或使用 `/rrce build` 执行。施工前会检查区块加载、既有轨道冲突、弯道半径、复线间距与改动方块数量，全部通过后再一次性完成。单次施工最多改动 100000 个方块。
- **撤销 / 重做**按快照强制恢复，包含箱子等方块实体的完整数据。对最近一次施工的第一次撤销，还会一并恢复该次施工所使用的端点与选中位置；之后的连续撤销与重做只改变世界方块。
- 每位玩家保留最近 15 次施工记录，执行新的施工会清空重做栈。下线后记录保留 10 分钟，服务器重启后记录清空。
- 跨维度或区块未加载时撤销会被拒绝，并且不会部分修改世界。
- 施工完成后端点会被清空（撤销该次施工时可恢复）。施工设置会写入手持的施工物品，跨游戏重启保留。

## 十二、思索

把鼠标停在铁路施工图上并按住 **W**，可以观看五个思索章节：勘测铁路线路、规划并修建复线、开山修建路堑、修建贯通隧道，以及快速规划线路。快速规划工具只在该章节中示范，工具物品本身没有思索入口。思索使用独立场景，逐步演示施工过程。

## 十三、命令

所有命令都需要玩家手持施工物品或拥有 OP 2 权限，且旁观模式不可使用。

| 命令 | 功能 |
|---|---|
| `/rrce status` | 查看当前端点数、线路数量、轨间空格及可撤销次数 |
| `/rrce preview` | 切换持续预览 |
| `/rrce build` | 执行施工 |
| `/rrce clear` | 清空全部待施工端点 |
| `/rrce point <x> <y> <z>` | 在当前选中点之后精确添加端点；初始方向取玩家视线 |
| `/rrce pop` | 删除最后一个端点 |
| `/rrce undo` / `/rrce redo` | 撤销 / 重做 |
| `/rrce materials` | 列出 Create 及兼容模组当前注册的轨道材质 ID |
| `/rrce terrain reload` | 重新加载服务端 `config/rrce-terrain.json`，需 OP 2 权限 |
| `/rrce config direction <0-7>` | 调整选中端点的方向：0 东、1 东南、2 南、3 西南、4 西、5 西北、6 北、7 东北 |
| `/rrce config lines <1-16>` | 并行线路数 |
| `/rrce config spacing <1-32>` | 相邻轨道之间空出的方块数 |
| `/rrce config margin <0-16>` | 外侧路基距离 |
| `/rrce config threshold <1-64>` | 隧道障碍高度阈值 |
| `/rrce config cutAngle <5-85>` | 开山坡角（度） |
| `/rrce config tunnelHeight <3-32>` | 隧道内部净高 |
| `/rrce config tunnelSide <0-16>` | 隧道两侧净距 |
| `/rrce config wallThickness <1-8>` | 隧道墙厚 |
| `/rrce config roofThickness <1-8>` | 隧道顶板厚度 |
| `/rrce config replaceFoundation <0\|1>` | `0` 保留可承重路基，`1` 替换 |
| `/rrce config terrainWork <0\|1>` | `1` 开启地形施工，`0` 只铺路基与轨道 |
| `/rrce config foundation [方块ID]` | 路基方块；省略 ID 则取消设置，`minecraft:air` 则清除规划位置 |
| `/rrce config wall [方块ID]` | 隧道墙壁与顶棚方块；省略 ID 则取消设置，`minecraft:air` 则清除规划位置 |
| `/rrce config material <线路> <材质ID>` | 指定某条线路使用的轨道材质 |
| `/rrce config primary <线路> <0\|1>` | 指定某条线路的弯道主端，`1` 起点 / `0` 终点 |

## 十四、兼容性

- **Create: Steam ’n’ Rails（气鸣铁道）**：其注册的轨道材质会出现在材料列表中，选择后即可施工；移除后 RRCE 仍可单独加载。
- **Create Unlimited**：安装后会读取其放置检查设置。当放置检查对当前玩家关闭时，规划也会同步放宽坡道与弯道限制，但仍会拒绝轨道交叉与复线间距不足的规划；复线限界、方块冲突与单次施工规模始终由 RRCE 检查。
- **Create 扳手**：原有交互保持不变，不受本模组影响。

## 十五、常见提示

| 提示 | 含义与处理 |
|---|---|
| 至少需要两个轨道端点 | 施工与预览都要求至少两个端点 |
| 相邻轨道端点的水平距离至少需要 2 格 | 两个相邻端点过近 |
| 相邻端点的轨道方向差不能超过 90° | 调整端点方向，减小转折角度 |
| 坡道过陡 / 爬坡弯道过陡 | 拉开端点或减小高差 |
| 弯道半径太小 / S 弯过急 | 拉开端点、调整方向，或增加水平过渡段 |
| 弯道内的复线无法保持设定间距 | 拉开端点、减小线路数或调整间距 |
| 单次施工超过 100000 个方块 | 分批施工，或减小线路长度与数量 |
| 施工区块尚未加载 | 靠近施工范围，让相关区块先加载 |
| 施工范围含受保护方块 | 调整地形规则，或对当前施工图开启「所有方块视为地形」 |
| 坡道路基需要替换现有方块，请开启替换路基 | 在开山页开启「替换路基」 |
| 已有轨道与规划轨道不兼容 / 轨道位置被占用 | 清理冲突方块或改道 |
| 没有可撤销 / 可重做的施工 | 当前没有对应的施工记录 |
